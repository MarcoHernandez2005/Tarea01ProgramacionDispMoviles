# HolaTodos - Tarea 1: Programación de Dispositivos Móviles

Aplicación nativa para Android desarrollada para la materia de **Programación de Dispositivos Móviles** en la **Facultad de Ciencias, UNAM**. Muestra un diseño en arte ASCII de gatito acompañado de la información del alumno mediante un `TextView` en un contenedor `LinearLayout`.

## Información del Proyecto

* **Alumno:** Marco Antonio Hernández Torres
* **Institución:** Facultad de Ciencias, UNAM
* **Lenguaje:** Java 11+
* **IDE:** Android Studio (Koala / Ladybug o superior)
* **API Mínima:** API 24 (Android 7.0 Nougat)

## Requisitos Previos

* **Android Studio** instalado.
* **JDK 11** o superior configurado en el IDE.
* Un **Dispositivo Virtual Android (AVD)** configurado (ej. Pixel 6 con API 33) o un dispositivo físico Android con **Depuración por USB** y la opción **Instalar por USB** activadas (en dispositivos Xiaomi / POCO / Redmi).

## Pasos para clonar y ejecutar el proyecto

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/MarcoHernandez2005/Tarea01ProgramacionDispMoviles.git](https://github.com/MarcoHernandez2005/Tarea01ProgramacionDispMoviles.git)
   Abrir en Android Studio:

Selecciona Open (o File > Open).

Selecciona la carpeta interna del proyecto (HolaTodos).

Sincronizar Gradle:

Espera a que Android Studio indexe y sincronice los archivos. Si te lo solicita, haz clic en Sync Project with Gradle Files (ícono del elefante) o en el mensaje emergente Load Gradle Project.

Ejecutar la aplicación:

Selecciona tu emulador o dispositivo físico en la barra superior.

Presiona el botón de Run 'app' o la combinación de teclas Shift + F10.
